# Brisa Store — Glosario

| Término | Significado |
|---|---|
| Pedido | Compra realizada en la tienda, con un número identificador |
| Acreditación | Momento en que el pago se confirma y el pedido puede prepararse |
| Despacho | Momento en que el pedido sale hacia el correo |
| Código de seguimiento | Número para rastrear el envío en el correo |
| Cambio de talle | Reemplazo de un producto por otro talle del mismo artículo |
| Devolución | Retorno del producto a cambio del reembolso del dinero |
| Cupón | Código que da un descuento, por ejemplo `BIENVENIDA10` |
| Cuotas sin interés | Pago dividido sin recargo sobre el precio |
| Días hábiles | De lunes a viernes, sin contar feriados |
| Días corridos | Todos los días del calendario, incluidos fines de semana |
